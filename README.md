## ⚙️ الميزات الهندسية والتشغيلية (Core Features)

### 1. تزامن الرؤوس الثلاثية التام (3 Synchronized Drill Heads)
- محاكاة دقيقة لآلات DCA المزودة بـ 3 رؤوس حفر (T1, T2, T3) متباعدة بزاوية $120^\circ$ متناظرة.
- كل رأس يغطي قطاعاً دائرياً قياسه $120^\circ$، ليتكامل عمل الرؤوس الثلاثة بتغطية محيطية دائرية كاملة $360^\circ$.
- خوارزمية ذكية تضمن أن إجمالي عدد الثقوب $N$ مضاعف لـ 3 لضمان استواء وتماثل النقوش الصناعية.

### 2. قانون التباعد المنتظم للأقطار (Concentric Ring Progression)
- حساب قطر أول حلقة حفر $D_1$ تلقائياً من قطر الصينية الكلي $D$ مطروحاً منه الهامش الخارجي $M$:
  $$D_1 = D - M$$
- تناقص أقطار الطبقات اللاحقة بانتظام وفق قانون تباعد القطر $\Delta D$:
  $$D_i = D_1 - (i - 1) \cdot \Delta D$$
- ميزة **"احسب التباعد تلقائياً"** لحساب التباعد المتساوي الدقيق بين أول حلقة وآخر حلقة مستهدفة $D_{\text{last}}$.

### 3. المحاكي الزمني والحركي (Interactive Animation Simulator)
- محاكاة مرئية سلسة باستخدام تقنيات المتجهات وحسابات الإطارات اللحظية.
- إمكانية تشغيل، إيقاف مؤقت، تسريع (0.5x حتى 4x)، تقديم خطوة بخطوة، أو سحب شريط التوقيت (Scrubber).
- تمييز لوني ديناميكي للنقاط: نقاط محفورة، نقاط قيد الحفر، ورؤوس الحفر النشطة.

### 4. حزمة تصدير متعددة الصيغ
- **JSON للمواصفات الصناعية**: جاهز للتكامل مع متحكمات Xinje وTouchWin PLC.
- **CSV لجدول الإحداثيات**: يضم أرقام الطبقات، زوايا الدوران الدقيقة، والإحداثيات الديكارتية $(X, Y)$ لكل ثقب.
- **نسخ الحافظة بضغطة زر واحدة**: نص منسق بجدول شاشات الآلة لوضعه في سجلات التشغيل.

## 🛠️ دليل التشغيل خطوة بخطوة للفنيين والمشغلين (Operator Guide)

```
[1. القياس الفيزيائي] ──> [2. ضبط عدد الطبقات] ──> [3. فحص التداخل] ──> [4. نقل الوصفة للآلة]
      (قطر + هامش)             (التباعد + الزوايا)           (مؤشر الأمان الأخضر)        (شاشات TouchWin أو QR)
```

### الخطوة 1: ضبط الأبعاد الهندسية للصينية (Geometry)
1. افتح بطاقة **أبعاد الصينية والأداة (Tray & Tool Geometry)**.
2. أدخل **قطر الصينية الكلي** (مثلاً: 35 سم أو 350 مم).
3. أدخل **الهامش الخارجي** (المسافة المقاسة بالمسطرة بين حافة الصينية ومحيط أول حلقة حفر).
4. حدد **قطر سن الحفر (Tool Diameter)** لضمان حساب مسافات الخلوص الآمنة بدقة.

### الخطوة 2: اختيار عدد الطبقات وقانون التباعد (Layers & Spacing)
1. اختر عدد الطبقات المطلوبة (من طبقة واحدة حتى 7 طبقات).
2. حدد تباعد الأقطار $\Delta D$ أو اضغط على **"⚙ احسب التباعد تلقائياً"** بعد تحديد قطر أصغر حلقة مرغوبة $D_{\text{last}}$.
3. تأكد أن حركة رأس السيرفو الشعاعية ($\Delta D / 2$) أكبر من قطر سن الحفر لتفادي تداخل الدوائر متحدة المركز.

### الخطوة 3: تحديد زوايا الدوران وعدد الثقوب (Rotation Angles)
- **في النمط الموحد (Uniform):** حدد عدد ثقوب الطبقة الأساسية وزاوية الإزاحة بين الطبقات.
- **في نمط الآلة المخصص (TouchWin Machine Recipe):** أدخل زاوية خطوة الدوران (`Rotation Angle`) لكل رأس مباشرة (مثلاً: $12.0^\circ$ لـ 30 ثقباً، $15.0^\circ$ لـ 24 ثقباً، $20.0^\circ$ لـ 18 ثقباً).

### الخطوة 4: التحقق ونقل الوصفة للآلة
1. تحقق من شارة الأمان العلوية:
   - 🟢 **آمن تماماً (Safe)**: لا توجد تصادمات، يمكنك المتابعة.
   - 🟡 **تنبيه (Warning)**: مراجعة قيم الخلوص أو أزمنة الاستقرار.
   - 🔴 **خطأ هندسي (Collision)**: تداخل بين الثقوب، عدّل التباعد أو عدد النقاط فوراً.
2. انتقل إلى تبويب **"قائمة الوصفات وشاشات الآلة"** وافتح شاشة TouchWin المطابقة لإدخال الأرقام مباشرة في لوحة تحكم الآلة.

## 🖥️ مطابقة شاشات TouchWin PLC ووصفات الآلة (TouchWin LCD Mirror)

يحتوي التطبيق على محاكاة ومطابقة حقيقية لشاشات اللمس الخاصة بآلات DCA:

### 1. شاشات معلمات الزوايا (Angle Parameters 1 - 7)
- عرض زاوية الدوران لكل طبقة (`rotation angle`) بدقة عشرية واحدة.
- عرض زاوية الإزاحة الابتدائية (`add0, add1...`).
- بيان حالة تفعيل أو إيقاف كل طبقة (`Active / Disabled`).

### 2. شاشة المعاملات الآلية (Auto Parameters)
- **سرعة الدوران (Rotation Speed):** بالهرتز (Hz) الافتراضي 800 Hz.
- **سرعة التمدد (Expansion Speed):** لسيرفو المحور الشعاعي بالهرتز (Hz).
- **عدد الطبقات النشطة (Deflower Layer):** عدد حلقات الحفر الفعلية.
- **زمن ثبات سن الحفر (Deflower Time):** زمن نزول وخروج السن بالثواني (مثلاً 0.10 S = 100 ms).
- **طول التمدد (Expansion Length):** تباعد المحور بالمليمتر.
- **زمن الدورة المتوقع (Processing Time):** الحساب الرياضي الدقيق لزمن إنهاء الصينية بالكامل شاملاً أزمنة استقرار السيرفو (Mechanical Settling Ramps).

## 🛡️ نظام الحماية من التصادم وحساب الأمان (Safety & Collision Guard)

تم تزويد المنصة بنظام رقابة هندسي صارم يمنع حوادث التشغيل:

1. **فحص خلوص سن الحفر مع محيط الصينية الخارجي:**
   يتأكد النظام من أن الهامش لا يقل عن نصف قطر سن الحفر، حتى لا يخرج السن عن حافة الصينية.
2. **فحص الخلوص بين الدوائر متحدة المركز:**
   يتأكد من أن المسافة الشعاعية بين أي حلقتين متجاورتين أكبر من قطر السن لمنع تداخل الحلقات.
3. **فحص تباعد النقاط على نفس الحلقة:**
   حساب المسافة الوترية اللحظية ($Chord\ Distance$) بين كل ثقبين متتاليين والتأكد من أنها تتجاوز قطر السن مع هامش أمان فيزيائي.
4. **حماية نقطة المركز (Danger Hub):**
   تنبيه المشغل في حال اقتراب الطبقة الأخيرة من المركز لدرجة تتسبب في تصادم الرؤوس المقابلة.

## 📱 العمل الميداني دون اتصال بالإنترنت (PWA Offline Capability)

- **100% مستقل عن الشبكة**: يتم تخزين ملفات التطبيق والخطوط العربية واللاتينية محلياً على الجهاز عبر Service Worker مدمج.
- **أيقونة تثبيت رسمية**: إمكانية تثبيت التطبيق كتطبيق سطح مكتب أو تطبيق هاتف عبر شريط التثبيت التفاعلي `PWAInstallButton`.
- **مؤشر حالة الاتصال (Offline Indicator)**: شريط عائم يُشعر المشغل باستمرار عمل المنصة بكفاءة كاملة عند انقطاع الشبكة.
- **أمان وتوافق البيانات (Versioned Storage v3)**: التحقق من سلامة البيانات وهجرتها تلقائياً عند أي ترقية مستقبلية لمنع تعطل واجهة المستخدم.

## 🚀 التثبيت والتشغيل المحلي (Setup & Installation)

### المتطلبات الأساسية
- **Node.js** (إصدار 18 فما فوق)
- مدير الحزم **npm** أو **bun**

### خطوات التشغيل
1. استنساخ المستودع والدخول للمجلد:
```bash
cd hmi-tray-designer
```

2. تثبيت الحزم البرمجية:
```bash
npm install
```

3. تشغيل خادم التطوير المحلي:
```bash
npm run dev
```
سيفتح التطبيق تلقائياً على الرابط: `http://localhost:3000`

4. تشغيل اختبارات الوحدة (Automated Unit Tests):
```bash
npm test
```

5. بناء النسخة الإنتاجية (Production Build):
```bash
npm run build
```
